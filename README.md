# Лёгкость ОС — личная операционная система

Раньше приложение называлось Frame OS. Внутренние имена остались прежними для совместимости: переменные окружения `FRAME_*`, заголовок `X-Frame-OS`, служба `frame-os` в Связке ключей.

Локальное веб-приложение, которое собирает задачи, проекты, цели и заметки в одной панели и работает **поверх вашего Obsidian Vault**. Obsidian остаётся главным хранилищем: «Лёгкость» читает и записывает обычные Markdown-файлы с YAML-свойствами, понимает вики-ссылки и структуру PARA: проекты, сферы, ресурсы, архив (Projects / Areas / Resources / Archive). Закрытой базы данных нет.

> Todoist — что сделать. Obsidian — что важно и какой есть контекст. «Лёгкость» — единый интерфейс, который связывает всё вместе.

## Что уже работает

| Раздел | Что делает |
|---|---|
| **Главная** | Задачи на сегодня и просроченные, события, платежи и сроки на 14 дней, платежи на 7 дней с кнопкой «Оплачено», тренировки и регулярные дела на сегодня, конец гарантии техники, активные проекты с прогрессом, текущий 12-недельный цикл, приоритеты дня, напоминания (собеседования, с кем связаться, документы на продление), календарь месяца, счётчики |
| **Сегодня** | План дня: приоритеты, задачи на дату, просрочки, сделанное, заметки дня, настроение и энергия, вечерний итог. Виды «День», «Неделя», «Месяц». Блок «Регулярное, тренировки и платежи»: что оплатить сегодня и завтра, тренировки, регулярные дела, фаза Луны, сон и вода, намерение дня. Всё сохраняется в ежедневную заметку |
| **Стратегия** | Цели с метрикой, горизонтом и прогрессом (вручную или по проектам), 12-недельные циклы с фазами, проекты без цели, создание целей, циклов и проектов под цель |
| **Проекты** | Список с фильтрами по статусу, тексту и избранному. Карточка проекта: прогресс, следующий шаг, задачи (из заметки проекта и его папки), этапы, бюджет, связи (цель, контакты, события), смена статуса и срока, перенос в архив с подтверждением |
| **Бэклог** | Открытые задачи без даты со всего хранилища, фильтры по проекту, приоритету, тегу и тексту, назначение срока |
| **Идеи** | Быстрые идеи, статусы, превращение в проект, задачу или гипотезу (исходная заметка сохраняется и получает ссылку на результат) |
| **Работа** | Воронка откликов: Интересно → Отклик → Ответ → Собеседование → Тестовое → Оффер / Отказ → Архив. Вакансия хранит компанию, должность, ссылку, зарплату, рекрутера, дату отклика, версию резюме, сопроводительное письмо, собеседования, тестовое, следующий шаг и результат. Каждая смена статуса пишется в историю заметки. Собеседования и сроки тестовых попадают в календарь, тестовое и следующий шаг становятся задачами. Версии резюме и портфолио с подсчётом, в скольких откликах они использованы |
| **Клиенты и контакты** | Лёгкая CRM: люди и компании. У человека — компания, должность, телефон, email, ссылки, вид (клиент, рекрутер, коллега…), статус клиента, последняя связь и следующий контакт. Запись общения добавляет строку в «Историю общения», обновляет даты и по желанию создаёт договорённость задачей со сроком. Карточка компании собирает людей, вакансии, задачи и документы. Кому пора написать — на главной и в календаре |
| **Документы** | Паспорт, РВП/ВНЖ, визы, договоры, дипломы, сертификаты, страховки, гарантии: владелец, где хранится оригинал, даты выдачи и окончания, за сколько дней напомнить, организация. Состояния «действует / пора продлевать / истёк / бессрочный», задача на продление в один клик, предупреждения о небезопасном хранении |
| **Финансы** | Доходы и расходы по месяцам, бюджет по категориям с лимитами (план, факт, прогноз до конца месяца, перерасход красным), подписки, разовые и регулярные платежи, долги с графиком, накопления с целью. Кнопка «Оплачено» записывает расход в операции и переносит дату следующего платежа. Банки не подключаются: всё вводится вручную или из заметок |
| **Спорт и здоровье** | Тренировки (план, выполнено, пропущено, «не отмечена»), упражнения с подходами и весом и прогресс по ним, повтор тренировки, сон, качество сна, восстановление, вода, вес, шаги и питание в ежедневной заметке, графики за 14 дней, регулярные процедуры. Раздел только ведёт записи, диагнозов и назначений не даёт |
| **Чтение и обучение** | Книги, статьи, видео и курсы со статусом и прогрессом (страницы, уроки, проценты), цитаты, выводы, действия из материала (становятся задачами), навыки с уровнем, журналом занятий и минутами за неделю. Материал связывается с проектом, навыком и идеей |
| **Практики** | Намерение дня, журнал практик с минутами, состояния с оценкой, благодарности, наблюдения, расклады. Всё пишется в секции ежедневной заметки. Серия дней, минуты за неделю и месяц, фаза Луны и лунный день, регулярные практики |
| **Дом** | Регулярные дела с интервалом, бытовые дела, список покупок (покупка с ценой сразу пишет расход в «Финансы»), техника с гарантией и обслуживанием, коммунальные платежи |
| **Знания** | Заметки, инструкции, исследования и ссылки из Obsidian; полнотекстовый поиск с фильтрами (вид, тег, папка PARA, всё хранилище); связи: исходящие, обратные, «висячие» ссылки с созданием недостающей заметки, упоминания без ссылки, похожие по тегам; связь добавляется строкой в секцию «Связи» |
| **Путешествия** | Поездки с датами, бюджетом и фазой по датам (впереди, в поездке, прошла); билеты и брони с кодом и оплатой (оплата пишет расход «Путешествия» в «Финансы»); маршрут по дням; список вещей с готовыми шаблонами (в бэклог не попадает); проверка срока документов к дате возвращения; поездки и брони в календаре, на «Главной» и в «Сегодня» |
| **Отношения** | Дни рождения (год можно не указывать) и важные даты каждый год в календаре; напоминания заранее; ритм общения «раз в N дней» с кнопкой «Связались»; договорённости со всеми людьми; идеи подарков и история подарков (сумма уходит расходом «Подарки») |
| **Дневник и итоги** | Запись дня в секцию «Дневник» ежедневной заметки, настроение и энергия, подсказки-вопросы, серия дней; итоги недели и месяца: цифры (задачи, просрочки, настроение, сон, тренировки, практики, деньги), графики по дням, выводы по правилам и сравнение с прошлым периодом; сохранение итогов в Obsidian с вопросами для рефлексии (повторное сохранение пересчитывает цифры и не трогает ваши ответы) |
| **Помощник** | План дня (три главных дела, обязательное, что перенести при перегрузе), приоритеты с объяснением «почему», разбор просрочек по давности, дела из текста заметки → задачи, советы по поиску работы и воронка откликов, связанные записи и следующий шаг для проекта, цели, вакансии, контакта или заметки. Работает по правилам на этом компьютере, без платного ИИ; любое изменение — только по вашей кнопке |
| **Регулярные дела** | Общий механизм для здоровья, практик и дома: интервал в днях, дата последнего выполнения, следующий срок и просрочка. Кнопка «Сделано» переносит срок |
| **Заметки** | Просмотр Markdown с рабочими вики-ссылками, свойства, задачи, обратные и исходящие ссылки, редактирование с защитой от перезаписи чужих правок |
| **Каркас** | Боковая навигация, глобальный полнотекстовый поиск (⌘K или /), быстрый ввод (N), избранное, светлая/тёмная/системная тема, адаптивная вёрстка, пустые состояния, понятные ошибки, индикатор синхронизации |

Изменения, сделанные в самом Obsidian, появляются в интерфейсе автоматически, без перезагрузки.

### Todoist

Модуль `packages/todoist` синхронизирует задачи с Todoist в обе стороны (через Todoist API версии 1):

- на Главной и в разделе «Сегодня» есть блок Todoist: просроченные и сегодняшние задачи, отметка выполнения (повторяющиеся переходят на следующую дату), быстрый ввод со сроком текстом («завтра», «каждый понедельник»), кнопка синхронизации, разбор конфликтов;
- в Бэклоге у каждой задачи есть кнопка «В Todoist»: задача уходит в выбранный проект Todoist со ссылкой `obsidian://` на заметку, а строка в заметке получает метку `[todoist:: id]` и пропадает из бэклога;
- выполнение такой задачи в Todoist отмечает строку `✅` в Obsidian, и наоборот;
- без сети изменения копятся в очереди и уходят при следующей синхронизации (автоматически каждые 5 минут);
- удалить задачу можно только с явным подтверждением.

Ключ API (Todoist → Настройки → Интеграции → Для разработчиков) задаётся одним из способов и никогда не попадает в репозиторий, хранилище, кэш или логи:

```bash
# 1. Переменная окружения (можно положить в .env — он в .gitignore)
TODOIST_API_TOKEN=... npm start
# 2. Файл, читаемый только вами
chmod 600 ~/.config/frame-os/todoist.token && TODOIST_API_TOKEN_FILE=~/.config/frame-os/todoist.token npm start
# 3. Связка ключей macOS (токен спросят интерактивно)
security add-generic-password -s frame-os -a todoist -w
```

Проверить ключ без изменений в Todoist: `npm run check:todoist`. Статус подключения виден в Настройках. Подробности в [packages/todoist/README.md](packages/todoist/README.md).

## Запуск

Нужен **Node.js 22** или новее.

```bash
git clone https://github.com/majstroff/claude-cloud-test.git frame-os
cd frame-os
npm install
npm run build
FRAME_VAULT_PATH="$HOME/Documents/MyVault" npm start
```

Откройте http://127.0.0.1:4317.

Без `FRAME_VAULT_PATH` приложение запускается на **копии тестового хранилища** (`sample-vault` копируется в `.data/sample-vault`), оригинал в репозитории не меняется. Это удобно, чтобы сначала посмотреть, как всё работает. Даты в тестовом хранилище стоят вокруг 24 ноября 2026, поэтому позже часть задач будет просроченной — так и задумано.

Совет: прежде чем направлять «Лёгкость» на настоящее хранилище, сделайте его резервную копию (или держите vault в git). «Лёгкость» ничего не удаляет, но аккуратность не помешает.

### Режим разработки

```bash
npm run dev
```

Сервер API перезапускается при изменениях кода, интерфейс открывается на http://127.0.0.1:5173 с горячей перезагрузкой.

### Настройки

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `FRAME_VAULT_PATH` | копия `sample-vault` | Путь к Obsidian Vault, поддерживается `~` |
| `FRAME_DATA_DIR` | `.data` в папке проекта | Служебные данные приложения: избранное, переопределения папок |
| `FRAME_PORT` | `4317` | Порт |
| `FRAME_HOST` | `127.0.0.1` | Адрес. Не меняйте без необходимости: данные хранилища станут доступны по сети |
| `FRAME_LOG` | — | `1` включает журнал запросов |
| `TODOIST_API_TOKEN` / `TODOIST_API_TOKEN_FILE` | — | Ключ Todoist (см. выше); без него Todoist показывается как «Нужен ключ» |

## Как «Лёгкость» понимает хранилище

Папки находятся автоматически по названиям (`Projects`/`1 Projects`/`Проекты`, `Areas`, `Resources`, `Archive`, `Inbox`, `Goals`/`Цели`, `Cycles`, `Ideas`/`Идеи`, `Daily`/`Journal`/`Дневник`, `Calendar`/`События`). Папка и формат ежедневных заметок берутся из настроек плагина «Ежедневные заметки» (`.obsidian/daily-notes.json`), если он включён. Всё можно переопределить на странице «Настройки».

Тип заметки задаётся свойством `type`, иначе определяется по папке:

```yaml
---
type: project          # project | goal | cycle | idea | daily | event | payment | workout | contact | …
status: active         # active | planned | paused | done
goal: "[[Найти работу]]"
deadline: 2027-01-31
budget: 15000
---
```

- **Проект** — заметка в папке проектов (или `Projects/Сайт/Сайт.md`). Задачи проекта — из самой заметки, из заметок в его папке и из заметок со свойством `project: "[[Проект]]"`. Прогресс = выполненные / все задачи (или свойство `progress`).
- **Цель** — `type: goal`; прогресс считается по проектам, у которых `goal` ссылается на цель.
- **12-недельный цикл** — `type: cycle` и `start: ГГГГ-ММ-ДД`; цели привязываются свойством `cycle` в цели или списком `goals` в цикле.
- **Идея** — `type: idea`, статусы `new`, `hypothesis`, `parked`, `converted`.
- **Событие, платёж, тренировка** — любая заметка со свойством `date` (и по желанию `time`, `amount`) попадает в календарь и на главную.
- **Вакансия** — `type: vacancy` в папке `Areas/Работа/Вакансии`. Свойства: `status`, `position`, `company`, `url`, `salary`, `recruiter`, `applied`, `resume`, `interview`, `interview_time`, `test_due`, `next_step`, `next_date`, `result`, `project`. Секции `## Описание`, `## Сопроводительное письмо`, `## Собеседования`, `## Задачи`, `## История`. Если указан `project: "[[Поиск работы]]"`, задачи вакансии считаются задачами проекта, а цель проекта связывает всю цепочку цель → проект → вакансия → задача → контакт.
- **Резюме и портфолио** — `type: resume` / `type: portfolio` в `Areas/Работа/Материалы`, свойства `version`, `url`, `updated`.
- **Компания** — `type: company` в `Resources/Компании`: `kind` (employer, client, partner…), `status`, `website`, `industry`, `city`.
- **Контакт** — `type: contact` в `Resources/Контакты`: `company`, `role`, `kind`, `client_status`, `phone`, `email`, `links`, `last_contact`, `next_contact`. Секции `## Заметки`, `## Договорённости` (задачи), `## История общения` (строки `- ГГГГ-ММ-ДД · канал: текст`).
- **Документ** — `type: document` в `Areas/Документы`: `doc_type` (passport, residence, visa, contract, diploma, certificate, insurance, warranty, medical, other), `owner`, `storage`, `number`, `issued`, `expires`, `remind_days`, `organization`, `sensitive`. Если `remind_days` не задан, срок напоминания зависит от типа (паспорт и РВП/ВНЖ — 180 дней, страховка — 30).
- Значение ссылочного свойства (`company`, `recruiter`, `resume`, `organization`, `project`) записывается как `[[Заметка]]`, если такая заметка есть, иначе остаётся текстом. При создании вакансии или контакта можно сразу создать карточку компании.
- **Задачи** — строки `- [ ]` в формате плагина Obsidian Tasks: `📅` срок, `⏳` запланировано, `✅` выполнено, `⏫🔼🔽` приоритет, `🔁 every week` повтор. Поля Dataview `[due:: …]` тоже понимаются. При выполнении повторяющейся задачи создаётся следующее повторение, как в Obsidian Tasks.
- **Ежедневная заметка** — секции `## Приоритеты`, `## Задачи`, `## Заметки`, `## Итог дня`; настроение и энергия хранятся в свойствах `mood` и `energy`.
- **Папки разделов** (находятся по названию, меняются в «Настройках»): `Areas/Финансы`, `Areas/Здоровье`, `Resources/Обучение`, `Areas/Практики`, `Areas/Дом`, `Resources/Знания`, `Areas/Путешествия`, `Areas/Отношения`, `Areas/Итоги`.
- **Операции** — по одной заметке на месяц `Areas/Финансы/Операции/ГГГГ-ММ.md` (`type: ledger`) с таблицей `| Дата | Тип | Сумма | Категория | Описание | Связь |`. Тип: `Доход`, `Расход`, `Накопления`. Таблицу можно править прямо в Obsidian.
- **Бюджет** — `Areas/Финансы/Бюджет.md` (`type: budget`): свойство `income` (план дохода) и таблица `| Категория | Лимит |` в секции `## Лимиты`.
- **Подписка** — `type: subscription`: `amount`, `period` (weekly, monthly, quarterly, yearly), `next_payment`, `category`, `status` (active, paused, cancelled). **Платёж** — `type: payment`: `date`, `amount`, `category`, `recurrence` (none, monthly, quarterly, yearly), `status` (planned, paid, cancelled). **Долг** — `type: debt`: `direction` (i_owe, owed_to_me), `counterparty`, `amount`, `remaining`, `monthly_payment`, `next_payment`, `due`, `rate`. **Накопление** — `type: savings`: `kind` (reserve, goal, purchase), `target`, `current`, `monthly`, `deadline`, `goal`. Оплата и взносы пишутся в секцию `## История`.
- **Тренировка** — `type: workout` в `Areas/Здоровье/Тренировки`: `date`, `time`, `kind` (strength, run, cardio, swim, bike, yoga, stretch, walk, other), `status` (planned, done, skipped), `duration`, `distance`, `effort` (1–5). Упражнения — таблица `| Упражнение | Подходы | Повторы | Вес, кг |` в секции `## Упражнения`.
- **Показатели дня** — свойства ежедневной заметки `sleep`, `sleep_quality`, `recovery`, `water`, `weight`, `steps`; питание — секция `## Питание`.
- **Материал** — `type: book | article | video | course` в `Resources/Обучение`: `status` (want, active, paused, done, dropped), `author`, `url`, `progress`, `total`, `unit` (pages, lessons, percent, minutes), `started`, `finished`, `rating`, `project`, `skill`, `goal`. Секции `## Цитаты` (блоки `>`), `## Выводы`, `## Действия` (задачи). **Навык** — `type: skill`: `kind` (skill, language), `level`, `target_level`, `weekly_minutes`, журнал занятий в `## Журнал` (`- ГГГГ-ММ-ДД · 30 мин: текст`).
- **Практики** — секции ежедневной заметки `## Намерение`, `## Практики` (`- 07:30 · Медитация · 15 мин: текст`), `## Состояния`, `## Благодарности`, `## Наблюдения`, `## Расклады`.
- **Регулярное дело** — `type: routine` в `<папка раздела>/Регулярное`: `sphere` (health, practice, home), `every` (дней), `last_done`, `start`, `time`, `status`. В календарь попадают повторения дел с интервалом от недели, ежедневные показываются только ближайшим сроком.
- **Знания** — `type: note` (и заметки без type), `instruction`, `research` (`question`, секции Источники/Выводы/Следующие шаги), `bookmark` (`url`, `read`, `why`) в `Resources/Знания`. Конфиденциальные заметки и документы в «Знания» и поиск раздела не попадают.
- **Путешествия** — `type: trip` в `Areas/Путешествия` (`destination`, `start`, `end`, `budget`, `travelers`, `documents: ["[[Паспорт]]"]`, секции «Маршрут» со строками `- 2026-12-18 · …` и «Список вещей» с галочками); `type: booking` в `Areas/Путешествия/Брони` (`trip`, `kind`, `date`, `time`, `end_date`, `confirmation`, `cost`, `paid`).
- **Отношения** — у контакта `birthday: 1990-03-15` или `birthday: 03-15` и `contact_every: 30`; важные даты `type: important_date` (и старые `type: birthday`) в `Areas/Отношения/Даты` с `date`, `kind`, `person`, `yearly`, `remind_days`; подарки — секции «Идеи подарков» и «Подарки».
- **Дневник** — секция `## Дневник` ежедневной заметки (рядом с `## Итог дня`). **Итоги** — `type: review` в `Areas/Итоги`: `period` (week, month), `start`, `end`; разделы «Цифры», «Наблюдения», «Сделано», «Не сделано в срок» заполняет программа, «Что получилось», «Что не получилось», «Чему научился», «Фокус на следующий период» — вы.
- **Дом** — техника `type: appliance` в `Areas/Дом/Техника` (`brand`, `model`, `room`, `purchased`, `price`, `warranty_until`, обслуживание в `## Обслуживание`), список покупок `Areas/Дом/Покупки.md` (`type: shopping`), бытовые дела `Areas/Дом/Бытовые дела.md` (`type: chores`). Коммунальные платежи — платежи с категорией «Жильё» или «Коммунальные».

## Безопасность и данные

- Сервер слушает только `127.0.0.1`, отвечает только на `localhost` (защита от DNS rebinding), а изменяющие запросы требуют заголовка `X-Frame-OS`, поэтому сторонний сайт в браузере не может писать в хранилище.
- Записываются только `.md`-файлы внутри хранилища; пути вне него, в `.obsidian` и в скрытые папки запрещены.
- Запись атомарная (временный файл + переименование). Если файл изменили в Obsidian после открытия, «Лёгкость» не перезапишет его и покажет конфликт.
- Безвозвратно ничего не удаляется. Кнопка «Удалить» (в заметке, проекте, идее, вакансии, контакте, документе, записи) после подтверждения переносит файл в корзину Obsidian — папку `.trash` в хранилище, откуда его можно вернуть. Проекты можно также переместить в архив.
- Заметки со свойством `sensitive: true` (или тегом `#sensitive`) не показывают текст в поиске и не будут передаваться ИИ-помощнику.
- **Документы.** Номер документа хранится в свойстве `number` заметки. **Внимание: это обычный Markdown-файл, номер в нём записан открытым текстом.** Это нормально, пока хранилище лежит только на вашем компьютере (без Obsidian Sync и других облаков); для защиты от посторонних на самом компьютере включите шифрование диска (FileVault). В интерфейсе номер скрыт (видны последние 4 символа), полностью он показывается только по кнопке «Показать»; в поиск и общий список заметок он не попадает. Сканы и фото в хранилище не загружаются. Новые паспорта, РВП/ВНЖ, визы, договоры, дипломы, страховки и медицинские документы по умолчанию создаются конфиденциальными. Карточка документа предупреждает, если в заметке есть ссылка на скан внутри хранилища (он лежит без шифрования), номер записан в тексте заметки (там он не скрывается) или важный документ не помечен как конфиденциальный.
- **Помощник** работает только на этом компьютере по понятным правилам: никаких внешних сервисов и платных моделей, данные никуда не отправляются. Он только предлагает, а срок, новую задачу или приоритеты дня меняет обычный метод API после вашего нажатия (замена уже записанных приоритетов просит второе подтверждение). Заметки он читает только через проверку `aiAccess`: документы и конфиденциальные заметки закрыты, пока в заметке явно не указано `ai: true`; `ai: false` закрывает любую заметку. Если когда-нибудь понадобится внешняя модель, её можно подключить как ещё один движок в `packages/vault/src/assistant.ts` с той же проверкой.
- Поисковый индекс живёт в памяти и пересобирается из файлов — его можно потерять без последствий. Избранное и настройки папок лежат в `FRAME_DATA_DIR/state.json`, вне хранилища.
- Локальная копия задач Todoist и очередь отправки лежат в `FRAME_DATA_DIR/todoist-cache.json` (права 600, без ключа API).

## Проверки

```bash
npm run typecheck   # TypeScript во всех пакетах
npm test            # тесты: разбор Markdown/YAML/задач, запись в vault, конфликты, API, Todoist (API замокан)
npm run build && npm run test:e2e   # 38 сквозных сценариев в браузере (нужен Playwright)
```

Для e2e: `npm i -D playwright && npx playwright install chromium`. Скрипт запускает сервер на временной копии тестового хранилища и проверяет быстрый ввод, выполнение задачи с записью `✅` в файл, вечерний итог, поиск, создание проекта под цель, превращение идеи в проект, перенос задачи из бэклога, вакансию по воронке с собеседованием в календаре, запись общения с контактом и договорённостью, создание конфиденциального документа со скрытым номером и задачей на продление, напоминания на главной, подхват правок из Obsidian, операцию и оплату подписки в «Финансах», выполненную тренировку и показатели дня, отметку регулярного дела, прогресс книги, запись практики, покупку с расходом в финансы, поиск и связи в «Знаниях», оплату брони и список вещей поездки, «Связались» и идею подарка в «Отношениях», запись дневника, сохранение итогов недели, план дня и задачи из заметки в «Помощнике», закрытость документов для помощника, тёмную тему, мобильную ширину и сообщения об ошибках. `SCREENSHOTS=папка` сохраняет скриншоты.
