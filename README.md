# Frame OS — Personal Life OS

Локальное веб-приложение, которое собирает задачи, проекты, цели и заметки в одной панели и работает **поверх вашего Obsidian Vault**. Obsidian остаётся главным хранилищем: Frame OS читает и записывает обычные Markdown-файлы с YAML-свойствами, понимает вики-ссылки и структуру PARA: проекты, сферы, ресурсы, архив (Projects / Areas / Resources / Archive). Закрытой базы данных нет.

> Todoist — что сделать. Obsidian — что важно и какой есть контекст. Frame OS — единый интерфейс, который связывает всё вместе.

| **Идеи** | Быстрые идеи, статусы, превращение в проект, задачу или гипотезу (исходная заметка сохраняется и получает ссылку на результат) |

Версии резюме и портфолио с подсчётом, в скольких откликах они использованы |

У человека — компания, должность, телефон, email, ссылки, вид (клиент, рекрутер, коллега…), статус клиента, последняя связь и следующий контакт. Запись общения добавляет строку в «Историю общения», обновляет даты и по желанию создаёт договорённость задачей со сроком. Карточка компании собирает людей, вакансии, задачи и документы. Кому пора написать — на главной и в календаре |

### Todoist

Модуль `packages/todoist` синхронизирует задачи с Todoist в обе стороны (через Todoist API версии 1):

- на Главной и в разделе «Сегодня» есть блок Todoist: просроченные и сегодняшние задачи, отметка выполнения (повторяющиеся переходят на следующую дату), быстрый ввод со сроком текстом («завтра», «каждый понедельник»), кнопка синхронизации, разбор конфликтов;
- в Бэклоге у каждой задачи есть кнопка «В Todoist»: задача уходит в выбранный проект Todoist со ссылкой `obsidian://` на заметку, а строка в заметке получает метку `[todoist:: id]` и пропадает из бэклога;
- выполнение такой задачи в Todoist отмечает строку `✅` в Obsidian, и наоборот;
- без сети изменения копятся в очереди и уходят при следующей синхронизации (автоматически каждые 5 минут);
- удалить задачу можно только с явным подтверждением.

Ключ API (Todoist → Настройки → Интеграции → Для разработчиков) задаётся одним из способов и никогда не попадает в репозиторий, хранилище, кэш или логи:

```bash
# 1. Переменная окружения (можно положить в .env — он в .gitignore)
TODOIST_API_TOKEN=... npm start
# 2. Файл, читаемый только вами
chmod 600 ~/.config/frame-os/todoist.token && TODOIST_API_TOKEN_FILE=~/.config/frame-os/todoist.token npm start
# 3. Связка ключей macOS (токен спросят интерактивно)
security add-generic-password -s frame-os -a todoist -w
```

Проверить ключ без изменений в Todoist: `npm run check:todoist`. Статус подключения виден в Настройках. Подробности в [packages/todoist/README.md](packages/todoist/README.md).

## Запуск

Нужен **Node.js 22** или новее.

```bash
git clone https://github.com/majstroff/claude-cloud-test.git frame-os
cd frame-os
npm install
npm run build
FRAME_VAULT_PATH="$HOME/Documents/MyVault" npm start
```

Откройте http://127.0.0.1:4317.

Без `FRAME_VAULT_PATH` приложение запускается на **копии тестового хранилища** (`sample-vault` копируется в `.data/sample-vault`), оригинал в репозитории не меняется. Это удобно, чтобы сначала посмотреть, как всё работает. Даты в тестовом хранилище стоят вокруг 24 ноября 2026, поэтому позже часть задач будет просроченной — так и задумано.

Совет: прежде чем направлять Frame OS на настоящее хранилище, сделайте его резервную копию (или держите vault в git). Frame OS ничего не удаляет, но аккуратность не помешает.

### Режим разработки

```bash
npm run dev
```

Сервер API перезапускается при изменениях кода, интерфейс открывается на http://127.0.0.1:5173 с горячей перезагрузкой.

### Настройки

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `FRAME_VAULT_PATH` | копия `sample-vault` | Путь к Obsidian Vault, поддерживается `~` |
| `FRAME_DATA_DIR` | `.data` в папке проекта | Служебные данные Frame OS: избранное, переопределения папок |
| `FRAME_PORT` | `4317` | Порт |
| `FRAME_HOST` | `127.0.0.1` | Адрес. Не меняйте без необходимости: данные хранилища станут доступны по сети |
| `FRAME_LOG` | — | `1` включает журнал запросов |
| `TODOIST_API_TOKEN` / `TODOIST_API_TOKEN_FILE` | — | Ключ Todoist (см. выше); без него Todoist показывается как «Нужен ключ» |

## Как Frame OS понимает хранилище

Папки находятся автоматически по названиям (`Projects`/`1 Projects`/`Проекты`, `Areas`, `Resources`, `Archive`, `Inbox`, `Goals`/`Цели`, `Cycles`, `Ideas`/`Идеи`, `Daily`/`Journal`/`Дневник`, `Calendar`/`События`). Папка и формат ежедневных заметок берутся из настроек плагина «Ежедневные заметки» (`.obsidian/daily-notes.json`), если он включён. Всё можно переопределить на странице «Настройки».

Тип заметки задаётся свойством `type`, иначе определяется по папке:

```yaml
---
type: project          # project | goal | cycle | idea | daily | event | payment | workout | contact | …
status: active         # active | planned | paused | done
goal: "[[Найти работу]]"
deadline: 2027-01-31
budget: 15000
---
```

- **Проект** — заметка в папке проектов (или `Projects/Сайт/Сайт.md`). Задачи проекта — из самой заметки, из заметок в его папке и из заметок со свойством `project: "[[Проект]]"`. Прогресс = выполненные / все задачи (или свойство `progress`).
- **Цель** — `type: goal`; прогресс считается по проектам, у которых `goal` ссылается на цель.
- **12-недельный цикл** — `type: cycle` и `start: ГГГГ-ММ-ДД`; цели привязываются свойством `cycle` в цели или списком `goals` в цикле.
- **Идея** — `type: idea`, статусы `new`, `hypothesis`, `parked`, `converted`.
- **Событие, платёж, тренировка** — любая заметка со свойством `date` (и по желанию `time`, `amount`) попадает в календарь и на главную.
- **Вакансия** — `type: vacancy` в папке `Areas/Работа/Вакансии`. Свойства: `status`, `position`, `company`, `url`, `salary`, `recruiter`, `applied`, `resume`, `interview`, `interview_time`, `test_due`, `next_step`, `next_date`, `result`, `project`. Секции `## Описание`, `## Сопроводительное письмо`, `## Собеседования`, `## Задачи`, `## История`. Если указан `project: "[[Поиск работы]]"`, задачи вакансии считаются задачами проекта, а цель проекта связывает всю цепочку цель → проект → вакансия → задача → контакт.
- **Резюме и портфолио** — `type: resume` / `type: portfolio` в `Areas/Работа/Материалы`, свойства `version`, `url`, `updated`.
- **Компания** — `type: company` в `Resources/Компании`: `kind` (employer, client, partner…), `status`, `website`, `industry`, `city`.
- **Контакт** — `type: contact` в `Resources/Контакты`: `company`, `role`, `kind`, `client_status`, `phone`, `email`, `links`, `last_contact`, `next_contact`. Секции `## Заметки`, `## Договорённости` (задачи), `## История общения` (строки `- ГГГГ-ММ-ДД · канал: текст`).
- **Документ** — `type: document` в `Areas/Документы`: `doc_type` (passport, residence, visa, contract, diploma, certificate, insurance, warranty, medical, other), `owner`, `storage`, `number_last4`, `issued`, `expires`, `remind_days`, `organization`, `sensitive`. Если `remind_days` не задан, срок напоминания зависит от типа (паспорт и РВП/ВНЖ — 180 дней, страховка — 30).
- Значение ссылочного свойства (`company`, `recruiter`, `resume`, `organization`, `project`) записывается как `[[Заметка]]`, если такая заметка есть, иначе остаётся текстом. При создании вакансии или контакта можно сразу создать карточку компании.
- **Задачи** — строки `- [ ]` в формате плагина Obsidian Tasks: `📅` срок, `⏳` запланировано, `✅` выполнено, `⏫🔼🔽` приоритет, `🔁 every week` повтор. Поля Dataview `[due:: …]` тоже понимаются. При выполнении повторяющейся задачи создаётся следующее повторение, как в Obsidian Tasks.
- **Ежедневная заметка** — секции `## Приоритеты`, `## Задачи`, `## Заметки`, `## Итог дня`; настроение и энергия хранятся в свойствах `mood` и `energy`.

## Безопасность и данные

- Сервер слушает только `127.0.0.1`, отвечает только на `localhost` (защита от DNS rebinding), а изменяющие запросы требуют заголовка `X-Frame-OS`, поэтому сторонний сайт в браузере не может писать в хранилище.
- Записываются только `.md`-файлы внутри хранилища; пути вне него, в `.obsidian` и в скрытые папки запрещены.
- Запись атомарная (временный файл + переименование). Если файл изменили в Obsidian после открытия, Frame OS не перезапишет его и покажет конфликт.
- Ничего не удаляется: проекты можно только переместить в архив, и это требует подтверждения.
- Заметки со свойством `sensitive: true` (или тегом `#sensitive`) не показывают текст в поиске и не будут передаваться ИИ-помощнику.
- **Документы.** Frame OS хранит о документе только сведения: где лежит оригинал, сроки и не больше 4 последних символов номера — полный номер не принимается. Сканы и фото в хранилище не загружаются. Новые паспорта, РВП/ВНЖ, визы, договоры, дипломы, страховки и медицинские документы по умолчанию создаются конфиденциальными. Карточка документа предупреждает, если в заметке есть ссылка на скан внутри хранилища (он лежит без шифрования), похоже записан полный номер или важный документ не помечен как конфиденциальный.
- **ИИ-помощник** (появится на следующих этапах) получает заметки только через проверку `aiAccess`: документы и конфиденциальные заметки закрыты, пока в заметке явно не указано `ai: true`; `ai: false` закрывает любую заметку.
- Поисковый индекс живёт в памяти и пересобирается из файлов — его можно потерять без последствий. Избранное и настройки папок лежат в `FRAME_DATA_DIR/state.json`, вне хранилища.
- Локальная копия задач Todoist и очередь отправки лежат в `FRAME_DATA_DIR/todoist-cache.json` (права 600, без ключа API).

## Проверки

```bash
npm run typecheck   # TypeScript во всех пакетах
npm test            # тесты: разбор Markdown/YAML/задач, запись в vault, конфликты, API, Todoist (API замокан)
npm run build && npm run test:e2e   # 18 сквозных сценариев в браузере (нужен Playwright)
```

Для e2e: `npm i -D playwright && npx playwright install chromium`. Скрипт запускает сервер на временной копии тестового хранилища и проверяет быстрый ввод, выполнение задачи с записью `✅` в файл, вечерний итог, поиск, создание проекта под цель, превращение идеи в проект, перенос задачи из бэклога, вакансию по воронке с собеседованием в календаре, запись общения с контактом и договорённостью, создание конфиденциального документа с отказом принять полный номер и задачей на продление, напоминания на главной, подхват правок из Obsidian, тёмную тему, мобильную ширину и сообщения об ошибках. `SCREENSHOTS=папка` сохраняет скриншоты.
